# Codit — mapa do repositório

## Visão geral
Aplicação educacional web mobile-first, com páginas no App Router, serviços de domínio em src/modules e Supabase acessado pelo cliente. Há shells nativos para desktop e Android.

## Stack
Next.js 16.4.6 · React 19.3.1 · TypeScript 5.9 · Tailwind CSS 4 · Supabase JS 2 · Zod 4 · Vitest 5. Build estático por padrão; Tauri 2 e Capacitor 8.
